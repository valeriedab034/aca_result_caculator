# aca_result_caculator
Chào bạn, mình là Bùi Đỗ Bình. Đây là trang web chính thức cho phép tính điểm trung bình học tập của bạn dựa vào dữ liệu điểm số bạn cung cấp. Bạn có thể tính điểm trung bình của rất nhiều người (không giới hạn số lượng người). Nếu có bất kì vấn đề gì, vui lòng quét mã QR để liên hệ tôi qua Facebook nhé. Cảm ơn bạn rất nhiều!!! &lt;3
